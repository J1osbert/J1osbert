INTRODUCTION TO JAVASCRIPT

JAVASCRIPT CAN BE SAID TO BE A PRGRAMMING LANGUAGE THAT
ALLOWS THE ADDITION OF COMPLEX FUNCTIONALITIES TO WEB PAGES. BUT ONE
MAY ASK, HOW DID JAVASCRIPT COME ABOUT? WELL JAVASCRIPT WAS FIRST INTRODUCED IN 1995
WITH A DIFFERENT NAME, THE INITITIAL NAME WAS MOCAH, THEN AFTER SOME TIME IT WAS
CHANGED TO TYPESCRIPT, THEN FINALLY IN 1996 THE NAME WAS OFFICIALLY SET AT JAVASCRIPT.
ALONG THW LINE SEVERAL VERSION OF THE LANGUAGE WERE CREATED, AND THESE VERSION WERE RECOGNIZED
BY THE NAME ES1,ES2,ES3 UP UNTIL 1999 WHEN THE LAST VERSION WHICH WAS ES3 WAS CREATED.
THERE WAS A DECADE LONG SILENCE ON WHEN A NEW VERSION WILL BE CREATED. THERE WERE RUMOURS OF
A RELEASE IN 2008, BUT THAT DID NOT HAPPEN TILL 2009 WHEN ES4 WAS RELEASED.
WELL IT IS GOOD TO NOT THAT THE ES IS AN ABBREVIATION FOR EMCASCRIPT, AND THSI CAME ABOUT BECAUSE THE LANGUAGE WAS SUBMITTED
TO EMCA INTERNATIONLA FOR STANDARDIZATION.
MOVING ON, AFTER ES4 THEN CAME ES5 AND ES6. ES6 INTRODUCED FUNCTIONS LIKE

  1. CLASSES, MODULES, ARROWS
  2. ENHANCED OBJECT LITERALS
  3. TEMPLATE STRINGS
  4. DESTRUCTING
  5. DEFAULT AND REST PARAMETERS
  6. SPREAD OPERATOR
  7. LET AND CONST
  8. ITERATORS FOR...OF
  9. GENERATORS
  10. MAP AND SET
  11. PROXIES AND SYMBOLS
  12. PROMISES
  13. MATH, NUMBER, STRING, ARRAY, OBJECT API'S AND ETC.
